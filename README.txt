마라톤 카보로딩 앱 - 끼니별 직접 선택형

사용법
1. index.html을 열거나 정적 웹호스팅에 폴더 전체를 업로드합니다.
2. 체중/대회일/출발시간을 입력하면 D-3~대회 당일 아침 표가 자동으로 표시됩니다.
3. 각 끼니마다 밥/바나나/가래떡의 - / 숫자 / + 버튼으로 섭취량을 직접 조절합니다.
4. 끼니별 탄수화물, 하루 총량, 목표 대비 차이가 즉시 갱신됩니다.
5. 기존 구버전 캐시가 있으면 새 서비스워커가 자동 정리합니다.

업데이트 v4: 각 D-3/D-2/D-1/대회 당일 카드 상단에 목표량과 사용자가 배치한 음식의 탄수화물 합계, 부족/초과량을 실시간 표시합니다.
